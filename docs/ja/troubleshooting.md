# 困ったときは

いま見えている症状や、画面に出た言葉を下の一覧から探してください。各項目は
「確かめること」と「直し方」を、効きやすい順に並べています。かぎかっこの中は、端末のアプリと
PC のホストが実際に出す言葉そのままです(どちらも言語の設定に従うので、英語で出ることもあります)。

ここに無いときは [既知の問題](known-issues.md) を見て、それでもなければ
[知らせてください](#不具合を報告する)。

## まずホストの準備状況を見る

PC でホストのウィンドウを開き(タスクトレイのアイコンから)、［接続］タブを見てください。
いちばん上の**「準備状況」**が、PC 側の準備を自分で確かめています。全部そろっていれば
「準備できています」と出ます。足りないものがあると、その行を開いて直し方を書きます。

| 行 | 足りないときの表示 | 直し方 |
|---|---|---|
| **ドライバ** | 「入っていません。インストーラをもう一度実行してください」 | PrismDesk のインストーラをもう一度実行します。 |
| **デバイスノード** | 「ありません。ホストを停止して開始し直してください」 | ウィンドウ左下の「ホストを停止」を押してから「ホストを開始」を押します。 |
| **ドライバとの接続** | 「ドライバが応答していません。PC を再起動してください」 | PC を再起動します。 |
| **ファイアウォール** | 「規則がありません。インストーラをもう一度実行してください」 | インストーラをもう一度実行します。 |
| | 「規則が無効になっています。有効にするか、インストーラをもう一度実行してください」 | Windows Defender ファイアウォールで規則を有効に戻すか、インストーラをもう一度実行します。 |
| | 「規則が別の exe を指しています。インストーラをもう一度実行してください」 | インストーラをもう一度実行します。 |
| | 「規則のポートが設定と違います。インストーラをもう一度実行するか、設定タブでポートを既定に戻してください」 | インストーラをもう一度実行します(［設定］のポートの欄は「詳細表示」を入れたときだけ出ます)。 |
| | 「確認できません(別のファイアウォールが有効のようです。そちらで 6 つのポートを許可してください)」 | そのセキュリティソフトで、[Wi-Fi でつなぐ](setup-wifi.md#インストーラが開けたポート) にある 6 つのポートを許可します。 |
| **ポート** | 「別のプロセスが使っています。そのアプリを終了してください」 | 横に名前が出ているプログラムを終了します。 |
| **自動起動** | 「ログオン時に起動しません。設定タブで有効にできます」 | サインインのたびに待ち受けてほしいときだけ、［設定］の「Windowsのログオン時に自動起動する」を入れます。切っている間は「準備できています」の代わりにこの行が出ますが、端末からはつなげます。 |

左下の「詳細表示」を入れると、問題が無いときも 7 行すべてが出ます。この状態の画面の
スクリーンショットは、不具合を知らせてもらうときにもいちばん役に立ちます。

## PC が見つからない

### 「ホストはまだ見つかっていません」と出る

1. **PC で PrismDesk は動いていますか。**トレイのアイコンを見てください。ホストの
   ウィンドウ左下のボタンが「ホストを停止」なら待ち受けています。「ホストを開始」になっていたら
   押してください。
2. **2 台は同じネットワークにいますか。**同じルーターの、同じサブネットです。ゲスト用の SSID、
   AP アイソレーション、2.4 GHz と 5 GHz を分けているルーターでは PC が見えません。
3. **ホストの「準備状況」を見てください**([上](#まずホストの準備状況を見る))。
   ファイアウォールの規則が欠けていても、ネットワークが違うときと同じく PC が見えなくなります。
4. **探索を使わずにつないでください。**ホストの［接続］タブに QR コードと接続用の文字列が
   出ています。アプリで「QRコードを読み取る」を押すか、「ほかの繋ぎ方（アドレス指定・USB）」→
   「ホストを直接指定」を開いて文字列を貼り付けます。

この画面を開いている間は探索が続いていて、ホストが応答すればすぐに一覧に出ます。
詳しくは [Wi-Fi でつなぐ](setup-wifi.md#ホストが見つからないとき)。

### ホテルやカフェの Wi-Fi

ホテルやカフェの Wi-Fi は、端末どうしがつながらないようにしてあることが多く、PC が
見つかりません。PC の「モバイル ホットスポット」(Windows の設定 → ネットワークと
インターネット)をオンにして、端末をそこにつないでください。この経路のホストには
「ホットスポット」の印が付きます。選べるなら帯域は 5 GHz にしてください。PC の電池を
多めに使います。

### VPN を使っている

PC か端末で VPN を使っていると、探索で PC が見つからなくなったり、見つかってもつながら
なかったりします。

- **PC が見つからない。**探索は VPN を越えません。ホストの［接続］タブの接続用の文字列を、
  「ホストを直接指定」に貼り付けてください。一度つながれば、アプリはそのホストを覚えます。
- **見つかるのに、つなぐと失敗する。**VPN が家の中のネットワーク宛ての通信まで
  トンネルに流しています。VPN の設定で家の中のネットワークを対象から外す(「プライベート IP を
  除外」「LAN へのアクセスを許可」などの名前のことが多いです)か、PrismDesk のアプリを
  VPN の対象から外すか、VPN を切ってください。開発中に WireGuard で実際に起きました。
  VPN 側の設定の話で、PrismDesk の側からは変えられません。

### PC にネットワークアダプタが複数ある

VPN のアダプタ、仮想マシン用のネットワーク、2 枚目のネットワークカードも数に入ります。
このときホストの［接続］タブに「アダプタが 2 個あります。端末と同じネットワークのものを
選んでください…」と出て、「このホストのアドレス」に一覧が並びます。端末と同じネットワークの
アドレスの横の「使う」を押してください。QR コードと接続用の文字列もそれに合わせて変わります。
「USB (推奨)」が出ていれば、それを選んでください。

### 「ホストに接続できませんでした」

全文は「ホストに接続できませんでした。ホストが起動しているか、同じネットワークにいるか
確認してください。」です。原因は「ホストはまだ見つかっていません」と同じなので、
[そちら](#ホストはまだ見つかっていませんと出る) を順に確かめてください。

「ホストから応答がありません。接続はできましたが無応答です。」と出たときは、PC までは届いて
いますが、接続が最後まで進んでいません。ホストの「準備状況」と、［ログ］タブに赤い行が
出ていないかを見てください。

## つながらない

### PIN を求められる・PIN が通らない

「ペアリング PIN が必要です。」や「ペアリング PIN が一致しません。」と出たとき。

PIN は、ホストの［接続］タブで QR コードの右に出ている 6 桁の数字です。アプリの
「ペアリング PIN（6 桁）」に入れて「この PIN で再接続」を押してください。QR コードを読み取れば
入力は要りません。一度通れば、アプリが次から覚えます。

何度やっても通らないときは、誰かがホストの［設定］→「セキュリティ」で「PINを再生成」を
押したのかもしれません。PC の画面で PIN を見直してください。また、間違った PIN が続くと、
ホストはしばらくの間その端末からの PIN を全部断ります(正しい PIN でも「一致しません」と
出ます)。少し待ってから試してください。

アプリが「この接続は暗号化されていません。PIN は同じネットワークの誰からも読める形で
送られます。」と警告したときは、ホストの暗号化が切れています。PIN を平文で送るより、
ホストの［設定］→「セキュリティ」で「通信を暗号化する」を入れて、ホストを開始し直してください。

### 「ホストの証明書が想定と違います」

端末は、PC を証明書で覚えています。この表示は、そのアドレスの PC の証明書が前と違うという
意味です。どちらかです。

- **PC で証明書を作り直した**(［設定］→「セキュリティ」→「証明書を作り直す」。このボタンは
  「詳細表示」と暗号化の両方が入っているときだけ出ます)。
  ホストの QR コードを読み直し、聞かれたら PIN も入れ直してください。
- **別の PC である**か、ネットワークの誰かがあなたの PC のふりをしている。
  つながずに、自分のネットワークにいるかを確かめてください。

### 「別のホストが応答」

保存してあるアドレスで、証明書の違うホストが応答しました。ルーターがそのアドレスを
別の PC に割り当て直したことがよくある原因です。一覧のそのホスト自身の行からつないで
ください。自分の PC で証明書を作り直したのなら、QR コードを読み直してください。

### 「証明書の指紋が分かりません」

全文は「このホストは通信を暗号化していますが、証明書の指紋が分かりません。ホストの接続タブに
出ている QR コードか接続文字列を使ってください。」です。そのとおりにしてください。
QR コードにも接続用の文字列にも、指紋が入っています。

### 「ホストの同時接続数が上限に達しています」

ホストは、許している台数の端末をもうつないでいます。無料版でつなげるのは **1 台**、
Pro では 4 台までです。ほかの端末を 1 台切断して(その端末のアプリから、またはホストの
［接続］タブの「切断」で)、もう一度つないでください。

### 「このホストは暗号化された接続だけを受け付けます」

全文は「このホストは暗号化された接続だけを受け付けます。この端末のアプリを更新してください。」
です。アプリがホストより古いので、Google Play で更新してください。

### 「映像の受信ポート（…）を開けませんでした」

全文は「映像の受信ポート（…）を開けませんでした。他のアプリが使っているか、前回の接続が
残っています。アプリを再起動してください。」です。PrismDesk のアプリを完全に閉じて
(最近使ったアプリの一覧から払って)、開き直してください。

## 映っている間

### 「接続が切れました。再接続しています…」

アプリが自分でつなぎ直します。短い途切れなら、同じ仮想ディスプレイのまま続きます。
「ホストに繋ぎ直せませんでした」と出てあきらめたときは、「もう一度接続する」を押すか、
一覧からつないでください。

切れていた時間が長いと、新しい接続として始まり、Windows は仮想ディスプレイを作り直します。
そこに置いていたウィンドウがメインのモニタへ戻ってくることがあるので、移し直してください。

何度も切れるときは、ネットワークを疑ってください。2.4 GHz の Wi-Fi、弱い電波、混んだ
チャンネルなどです。アプリ自身も「2.4 GHz の Wi-Fi は途切れやすいので、5 GHz を勧めます。」と
出します。

### 「ホストが応答しません」

画面が黒くなり、「ホストが応答しません」と最後に受信してからの秒数が出ます。PC から数秒
何も届いていない、という意味です。PC がスリープした、ホストが止められた、ネットワークが
一瞬途切れた、のどれもありえて、端末からはどれかを見分けられません。

「ホストが戻れば自動的に映像が戻ります。」PC がスリープしていたら起こしてください。端末では
何もしなくてかまいません。待つのをやめるときは「コントロールを開く」を押して「切断」を選びます。

### 映像が来ない・ブロック状に崩れる

- **PC の画面が消えている間、「映像を待っています…」のまま進まない。**PC 自身のモニタが
  電源の設定で消えている間、仮想ディスプレイが絵を出さなくなるのを見ています。PC のマウスを
  動かすかキーを押して、画面を点けてください。
- **映像がブロック状に崩れたまま戻らない。**ホストの［接続］タブで「画面を描き直す」を
  押してください。完全な 1 枚を送り直します。
- **端末に「デコーダを起動できませんでした」と出る。**表示には試したコーデックと大きさが
  出ています。アプリの［設定］→「コーデック」を H.264 にするか、「仮想ディスプレイ解像度」を
  小さくして、つなぎ直してみてください。

### タブレットに PC と同じ画面が映る

2 枚目のデスクトップにしたかったのに、PC のモニタと同じものが映っているとき。Windows が
仮想ディスプレイを「画面の複製」にしています。ホストの［統計］タブと［ログ］タブにも
そう出ます。

- ホストの［設定］→「仮想ディスプレイ」の「仮想ディスプレイを常に拡張にする」が入っているか
  確かめるか(既定で入っています。誰かが切っていなければ入っています)、
- Windows の設定 → システム → ディスプレイ で「表示画面を拡張する」を選んでください。

アプリで「画面複製」を自分で選んだのなら、それが画面複製の動きです。アプリの［設定］→
「表示モード」を「画面拡張」にしてください。

### 端末から音が出ない

- **音声は、つなぐ前に決まります。**アプリの［設定］→「音声」を確かめて、つなぎ直して
  ください。接続してからは切り替えられません。
- **Windows で何か鳴っていますか。**送るものが無いとき、ホストの［統計］タブには
  「音声: 待機中(Windows で何も再生していません)」と出ます。これは故障ではありません。
- 「無音: 送っていますが音がありません。Windows の再生デバイスを確かめてください(切り替えた
  直後は鳴りません)」と出ていたら、Windows が PrismDesk の聞いていないデバイスに鳴らしているか、
  再生デバイスを切り替えた直後です。Windows のサウンドの設定で再生デバイスを確かめてください。

### お絵描きアプリがペンに反応しない

アプリのタブレット入力の設定を、WinTab ではなく **Windows Ink** にしてください。Krita での
具体的な手順は [ペン](pen.md) にあります。端末でも、最初にペンが触れたときに「ペン入力を
受信しました。ペイントソフトが反応しない場合は、アプリの設定でタブレット入力を Windows Ink に
してください。」と出ます。

### HDR にならない

つないだあと、アプリはホストが変えた設定とその理由を並べます。理由をここで探してください。

| アプリの表示 | 直し方 |
|---|---|
| 「HDR 表示は PrismDesk Pro の機能です。接続先のホストは無料版で動いているため、SDR で配信されます。」 | HDR には PC 側の Pro が要ります。 |
| 「この端末は HDR を表示できないため、SDR で配信されます。」 | 端末が HDR を使えません。[HDR](hdr.md) を見てください。 |
| 「HDR は H.265 でしか送れないため、SDR で配信されます。」 | アプリの［設定］→「コーデック」を H.265 か「既定」にします。 |
| 「Windows が仮想ディスプレイの HDR を有効にできなかったため、SDR で配信されます。」 | PC の 設定 → システム → ディスプレイ で PrismDesk のディスプレイを選び、「HDR を使用する」を入れます。 |
| 「この画面のエンコーダは H.265 を出力できないため、H.264 で配信されます。」 | PC のエンコーダが HDR を扱えません。[既知の問題](known-issues.md#intel-だけの-pc-の一部では-hdr-が使えない) を見てください。 |

**HDR で届いているのに SDR と同じに見える。**パネルによっては SDR より明るくできません。
アプリの「色空間」にそう出ます。[HDR](hdr.md#hdr-を活かせないパネル) を見てください。
本当に何が送られているかは、ホストで「詳細表示」を入れて、［接続］タブの「HDRの実測値」で
確かめられます。

### カメラが使えない

- 「端末カメラの Web カメラ化は PrismDesk Pro の機能です。」と出る。カメラには PC 側の
  Pro が要ります。
- **端末にカメラのボタンが無い。**ホストの［設定］→「仮想カメラ」の「端末のカメラを
  Windowsの仮想カメラとして出力する」が入っているか確かめてください(既定で入っています。
  誰かが切っていなければ入っています)。
- 「カメラの権限がありません。」と出る。「アプリの設定を開く」を押して、PrismDesk に
  カメラを許可してください。
- **使いたいアプリのカメラ一覧に PrismDesk Camera が無い。**そのアプリを閉じて開き直して
  ください。アプリはカメラの一覧を起動したときに読みます。詳しくは
  [Web カメラ](webcam.md#カメラの一覧に-prismdesk-camera-が出ない)。
- **Windows のカメラ アプリで写真が保存できない**(`0xA00F424F`)。カメラではなく
  Windows のライブラリの問題です。直し方は [Web カメラ](webcam.md) の
  「写真が保存できない」にあります。

## PC 側

### インストーラが止まる・入らない

- **「Windows によって PC が保護されました」。**「実行」を押す前に確かめられることを
  [こちら](smartscreen.md) に書いています。
- **Windows 10 で止まる。**PrismDesk には Windows 11(ビルド 22000 以降)が要ります。
  わざと止めています。
- **「The virtual display driver could not be installed.」と出る**(インストーラのこの
  メッセージは英語だけです)。理由は、メッセージに書かれている PrismDesk のフォルダの
  `setup.log` にあります。インストーラをもう一度実行して、同じメッセージがまた出たら、
  そのファイルを付けて [知らせてください](#不具合を報告する)。
- **「The firewall rules could not be added.」と出る。**PrismDesk は入りますが、最初に
  端末がつないだときに Windows が許可するかを聞いてくることがあります。許可してください。
  インストーラをもう一度実行すると、規則の追加をやり直します。
- **「Windows does not trust whoever signed the PrismDesk display driver」(0x800B0109)と
  出る。**手元のインストーラは配布用のものではありません。
  [Releases のページ](https://github.com/Asynchronous-0x4C/prismdesk-app/releases) から落とし直してください。

### 仮想ディスプレイが作れない

- 「ドライバが入っていないため、仮想ディスプレイを作れません。PrismDesk のインストーラを
  もう一度実行してください。」そのとおりにしてください。
- 「仮想ディスプレイのデバイスノード作成に失敗しました(管理者権限がありません)。」
  ディスプレイを作るには管理者の権限が要ります。スタートメニューから起動して Windows の
  確認を許可するか、サインイン時の自動起動に任せてください。
- 「準備状況」に「ドライバが応答していません。PC を再起動してください」と出る。PC を
  再起動してください。端末をつないだまま PC 自身のモニタが消えたあとに、これが起きたのを
  見ています。

### ウィンドウを閉じても終わらない

わざとです。ウィンドウを閉じても PrismDesk はタスクトレイに残り、端末を待ち受けています。
終わらせるときは、トレイのアイコンを右クリック →「終了」です。

### Pro の有効化に失敗する

| ホストの表示 | 直し方 |
|---|---|
| 「ライセンスキーの形式が違います。」 | 購入時のメールに届いた `PDESK-` で始まるキーを貼り付けます。 |
| 「このキーで有効化できる台数の上限に達しています。」 | 1 つのキーで 3 台の PC まで使えます。使わなくなった PC を、Polar の購入者ページで解除してください。 |
| 「Polar へ接続できませんでした。インターネット接続とファイアウォールを確認してください。」 | 有効化のときだけインターネットが要ります。そのあとはつながっていなくても Pro のまま使えます。 |
| 「試行が多すぎます。しばらく待ってから試してください。」 | 少し待ってから試してください。 |

注文に関わることは、公開の issue ではなく [support@prismdesk.app](mailto:support@prismdesk.app) へ
メールでお願いします。

### 「更新を確認できませんでした」

全文は「更新を確認できませんでした。インターネットに繋がっているか確かめてください。」です。
「更新を確認」は、押したときに https://prismdesk.app の小さなファイルを 1 つ読むだけです。最新の版は
いつでも [Releases のページ](https://github.com/Asynchronous-0x4C/prismdesk-app/releases) にあります。

## 不具合を報告する

役に立つのは 2 つです。診断ファイルと、「詳細表示」を入れた状態のホストの画面の
スクリーンショットです。

- **PC では:**［ログ］タブの「診断をエクスポート」で、`%LOCALAPPDATA%\PrismDesk\` に
  ファイルが 1 つできます。「フォルダを開く」でその場所が開きます。「不具合を報告」は、版・
  Windows のビルド・GPU を書き込んだ GitHub の issue の下書きを開きます。
- **端末では:**［設定］→「不具合を報告」→「診断を共有」で、ファイルの送り先を選べます。
  PIN や認証トークンは入っていません。

issue はどちらか一方から [Issues](https://github.com/Asynchronous-0x4C/prismdesk-app/issues/new/choose) に開いて、ファイルを付けて
ください。注文番号・ライセンスキー・
個人の情報が入るものは、公開の issue ではなく
[support@prismdesk.app](mailto:support@prismdesk.app) へ送ってください。
