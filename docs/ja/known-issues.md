# 既知の問題

**1.2.0** の時点のものです。直ったものも、直した版を添えてこのページに残します。
症状で検索してここに来た人が、その症状を確かめられるようにするためです。

ここに無いものは、下にあるそれぞれのページか [困ったときは](troubleshooting.md) にあるか、
まだ誰も見ていないものです。[知らせてください](https://github.com/Asynchronous-0x4C/prismdesk-app/issues/new/choose)。

## 直っていないもの

### Intel だけの PC の一部では HDR が使えない

一部の PC では、Intel の H.265 エンコーダがフレームを受け取ったまま何も出さなくなります。
PrismDesk はこれを見つけて **H.264** に切り替え、端末にも知らせるので、画面が真っ黒の
ままにはなりません。ただ、**HDR10 には H.265 が要る**ので、こうした PC では HDR が使えません。

PrismDesk の中で回避する方法はありません。NVIDIA の GPU も載っている PC なら NVENC を
使うので、この問題は起きません。

### HDR で配信中、小さなウィンドウの動画の色が濃すぎる

HDR で配信している間、ブラウザの小さなウィンドウで再生している動画の色が、濃すぎて出る
ことがあります。全画面の動画は正しい色です。一度こうなると、一時停止しても色は戻りません。
PrismDesk が画面を取り込む前の時点で、PC の上ですでに色が違っているので、配信で足されている
ものではありません。どこから来るのかはまだ分かっていません。

回避策: 動画を全画面か大きなウィンドウで見るか、SDR で配信してください。

### 2 台目の端末に自分の画面が作られないことがある

2 枚目の拡張ディスプレイを作るときに、Windows の間接ディスプレイの仕組みが
`0xD000000D` で失敗するのを見たことがあります。**4 台同時の試験では再現しませんでした。**
原因は分かっていません。起きたら一度切断してつなぎ直してください。私たちのほうで再現できて
いないので、診断ファイルを付けて issue を開いてもらえると助かります。

### VPN があると端末が PC を見つけられないことがある

PC と端末のどちらで動いている VPN でも、Wi-Fi でも USB テザリングでも、探索が届かなくなる
ことがあります。開発中に実際に起きました。VPN を入れていると何も見つからず、切るとすぐに
ホストが出ました。

探索だけが入口ではありません。ホストの接続用の文字列を、アプリの「ホストを直接指定」に
貼り付けてください。見つかるのにつながらないときは、VPN が家の中のネットワーク宛ての通信まで
トンネルに流しています。直し方は [困ったときは](troubleshooting.md#vpn-を使っている) に
あります。

### USB テザリングでノート PC の Wi-Fi が切れることがある

Wi-Fi につないでいるノート PC で USB テザリングを入れると、Wi-Fi の接続が切れることが
あります。ほかのことに Wi-Fi が要るなら、どちらかを選ぶことになります。
[USB でつなぐ](setup-usb.md) を見てください。

### WinTab を使うお絵描きアプリにはペンが見えない

故障ではありませんが、いちばんよく驚かれることです。**WinTab** に設定されたアプリには、
ペンがまったく見えません。**Windows Ink** に切り替えてください。Krita での設定は
[ペン](pen.md) にあります。

### HDR を活かせないパネルでは、HDR にしても何も変わらない

HDR に対応していると申告するのに、SDR より明るくできないパネルがあります。HDR10 で送られて
デコードもされますが、見た目は同じです。アプリはつなぐ前にそのことを知らせます。
[HDR](hdr.md) を見てください。

## PrismDesk のせいではないが、使っていると出会うもの

どちらも [Web カメラ](webcam.md) のページにあります。

- **Windows のカメラ アプリで写真が保存できない**(`0xA00F424F` / `0x80270200`)。
  Windows のライブラリの定義が壊れているためで、カメラを使わなくても起きます。
- **Discord で背面カメラが左右反転して見える。**Discord が自分の映像を反転して見せている
  ためです。相手には正しい向きで届いています。

同じページに、**カメラを使っているアプリがある間にホストを止めたり始めたりすると、
そのアプリが応答しなくなることがある**ことも書いています。先にカメラのアプリを閉じてください。

## 壊れてはいないが、よく聞かれること

- **フレームレートの数字は出していません。**フレームレートは Windows が画面を合成する間隔で
  決まります。メインのモニタが 75 Hz なら、出せるのは 75 / 37.5 / 25 で、60 はこの中に
  ありません。[よくある質問](faq.md) を見てください。
- **Windows 10 には対応していません。**インストーラはわざと止まります。
- **インストーラで SmartScreen の警告が出ます。**
  [「Windows によって PC が保護されました」](smartscreen.md) を見てください。
