# Web カメラ

PC で PrismDesk が動いている間、つないでいる端末のカメラが、**PrismDesk Camera** という
名前のふつうの Windows のカメラとして PC に出ます。カメラを選べるアプリなら、どれからでも
選べます。

カメラは **PrismDesk Pro** の機能です。PC が無料版だと、アプリに
「端末カメラの Web カメラ化は PrismDesk Pro の機能です。接続先のホストは無料版で動いています。」と
出ます。

## 使えるようにする

1. PC でホストのウィンドウを開き、［設定］→「仮想カメラ」の「端末のカメラをWindowsの
   仮想カメラとして出力する」が入っているか確かめます(既定で入っています)。登録が済むと、
   同じ欄に「仮想カメラ: Windowsに登録済み」と出ます。
2. 端末でいつもどおりつないだら、映像の右端のつまみから左へスワイプしてメニューを開き、
   「カメラ」を押します。このボタンは 1 が入っているときだけ出ます。最初のときは Android が
   カメラの権限を聞いてきます。
3. PC のアプリで **PrismDesk Camera** を選びます。

**カメラがあるのは、PC で PrismDesk が動いている間だけです。**ホストを止めると Windows から
デバイスが消え、始めると戻ります。

## どの設定がどこにあるか

| | |
|---|---|
| **端末が撮るもの**(解像度・フレームレート) | Android のアプリ: ［設定］→「カメラ（Pro）」。カメラが実際に申告した値だけが並びます。 |
| **Windows に見せるもの**(ほかのアプリから見える解像度とフレームレート) | ホストのウィンドウ: ［設定］→「仮想カメラ」→「出力解像度」。 |

撮る側をホストの出力より上げても、通信量と発熱が増えるだけです。出力解像度を変えて適用すると
カメラを作り直すので、使っていたアプリではカメラを選び直すことになります。

**前面と背面**は、同じメニューの「前面」/「背面」で切り替えます。映像の向きは端末の向きに
自動で合わせます。

サブモニタとカメラを同時に使えます。

## 確かめたもの

- Windows の **カメラ** アプリ —— 映像が出ます。カメラが動いているかをいちばん早く
  確かめられます。
- **Discord** —— 動きます。

ほかのアプリも同じように動く見込みです(ふつうの Media Foundation のカメラなので)。ただ、
試したのはこの 2 つです。

## Discord で背面カメラが左右反転して見える

**PrismDesk ではなく Discord の動きです。**Discord は自分の映像を反転して見せます。前面
カメラが反転して見えるのも同じ理由で、それが見分けどころです。経路のどこでも絵を反転して
いません。前面も背面も反転せずに送っていて、相手にはそのまま届いています。

自分で確かめるには、Windows の **カメラ** アプリで *PrismDesk Camera* を選び、背面カメラで
文字を映してください。読めれば、送っている絵は正しい向きです。

元の側で反転させないのは、そうすると相手全員に裏返しの絵を送ることになるからです。

## カメラの一覧に PrismDesk Camera が出ない

- **ホストは動いていますか。**カメラはホストが動いている間だけあります。
- **仮想カメラは入っていますか。**ホストの［設定］の欄に「Windowsに登録済み」「未登録」
  「無効」のどれかが出ています。
- **そのアプリは先に開いていませんでしたか。**アプリは起動したときにカメラの一覧を読みます。
  閉じて開き直してください。
- **PC のほかのソフトが登録を止めていることがあります。**ほかのプログラムのせいで仮想カメラが
  登録できなかった例を見ています。ホストは入っていると言うのに Windows の一覧に出ないなら、
  その方向を疑ってください。そして、名前を挙げてこのページに載せられるように
  [issue を開いて](https://github.com/Asynchronous-0x4C/prismdesk-app/issues/new/choose) ください。

## 写真が保存できない(`0xA00F424F` / `0x80270200`)

**これは PrismDesk ではありません。**Windows の **カメラ** アプリで写真を保存すると
`0xA00F424F <PhotoCaptureFileCreationFailed> (0x80270200)` で失敗する場合、2 つ目の番号は
Windows の `LIBRARY_E_NO_SAVE_LOCATION`、つまり「ライブラリに保存先が無い」です。**カメラを
まったく使わなくても起きます。**私たちのカメラを使っているときに出会ったので、PrismDesk の
問題に見えるだけです。

別の PC や別のアカウントからユーザーのプロファイルを持ってきた PC で起きます。フォルダも
その権限も正常なのに、ライブラリの定義だけが前のユーザーを指したままになっています。

**直し方:** エクスプローラーのナビゲーション ウィンドウで「ライブラリ」を右クリックし、
「既定のライブラリに戻す」を選びます(「ライブラリ」が出ていないときは、エクスプローラーの
表示の設定でナビゲーション ウィンドウにライブラリを表示させます)。実機で、直後から保存できる
ようになったのを確かめました。

それでも保存できないライブラリがあれば、そのライブラリのプロパティを開いて「既定値に戻す」を
使ってください。「既定のライブラリに戻す」は、自分で場所を足したライブラリは作り直しません。

映像そのもの(プレビュー、Discord、そのほか)は、このエラーの影響を受けません。

## ホストを止めたり始めたりしたら、カメラのアプリが応答しなくなった

**ホストを止める前・始める前に、カメラのアプリを閉じてください。**PrismDesk のカメラは
ホストと一緒に生まれて消えるので、ホストを止めると Windows からカメラのデバイスが消え、
それを掴んだままのアプリはうまく対処できないことがあります。実機では、Windows のカメラ
アプリを強制終了しなければなりませんでした。ホストで出力解像度を変えたときも同じことが
起きます。ホストはカメラを読んでいるアプリがあると、止める前に知らせます。

アプリを開き直してカメラを選び直せば戻ります。ほかのアプリがこの場面でどう動くかは
確かめていません。
