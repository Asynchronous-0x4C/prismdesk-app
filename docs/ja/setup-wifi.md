# Wi-Fi でつなぐ

ふだんの使い方です。ルーターの設定はいりません。アカウントも作りません。

## はじめて使うとき

1. **PC でインストーラを実行します。**ディスプレイドライバ、ファイアウォールの規則、
   サインイン時の自動起動は、インストーラがまとめて入れます。
   その前に Windows が警告を出すことが多いので、実行する前に
   [「Windows によって PC が保護されました」](smartscreen.md) で確かめられることを見てください。
2. **Android 端末に PrismDesk を入れます。**Google Play から(または
   [Releases のページ](https://github.com/Asynchronous-0x4C/prismdesk-app/releases) の APK から)。
3. **PC で PrismDesk が動いていることを確かめます。**インストールのときに
   「Windows にサインインしたら PrismDesk を起動して待ち受ける」に
   チェックを入れたままなら、もう動いています。タスクトレイのアイコンが目印です。
   ホストのウィンドウを閉じても止まらず、トレイに残ります。
4. **端末でアプリを開きます。**同じネットワークにあるホストが自然に一覧に出ます。
   押すと、保存してある設定でそのまま接続します。

準備はこれだけです。条件は、2 台が同じネットワーク(同じルーターの、同じサブネット)に
あることだけです。

PC 側の準備は、ホストが自分で確かめます。ホストのウィンドウの［接続］タブのいちばん上にある
**「準備状況」**は、ドライバ・ファイアウォールの規則・ポート・サインイン時の自動起動が
そろっていれば「準備できています」と出し、足りないものがあればその行を開いて直し方を書きます
(自動起動のチェックを外したときは、その行が開いたままになります。端末からはつなげます)。
詳しくは [困ったときは](troubleshooting.md#まずホストの準備状況を見る) を見てください。

## ホストが見つからないとき

アプリには**「ホストはまだ見つかっていません」**と出て、**「見つからないときは」**を
開くと確かめることが並びます。実際に原因だったことが多い順に:

| 確かめること | どういうときに起きるか |
|---|---|
| **PC で PrismDesk は動いていますか** | トレイにアイコンが無い。ホストのウィンドウで待ち受けを止めている。 |
| **2 台は同じネットワークにいますか** | ゲスト用の SSID、AP アイソレーション(端末どうしの通信を止める設定)、2.4 GHz と 5 GHz を別のネットワークとして分けているルーターでは、PC が見えません。PC は有線、端末は Wi-Fi で、ルーターがそれを別の区画として扱っている場合も同じです。 |
| **ホテルやカフェの Wi-Fi** | 端末どうしがつながらないようにしてあることが多いです。PC の「モバイル ホットスポット」をオンにして端末をそこにつなぐと、直接つながります。この経路のホストには「ホットスポット」の印が付きます。PC の電池を多めに使います。 |
| **VPN を使っていませんか** | PC と端末のどちらの VPN でも、探索が届かなくなることがあります。開発中に実際に起きました。VPN を入れていると何も見つからず、切るとすぐにホストが出ました。探索を使わずにつなぐ方法があります(下)。 |
| **2.4 GHz** | 使えますが途切れやすく、勧めません。アプリの同じ画面にも出ます。 |

この画面を開いている間は探索が続いていて、ホストが応答すればすぐ一覧に出ます。

## 探索を使わずにつなぐ

探索は便利なだけで、つなぐ方法はほかにもあります。ホストのウィンドウの［接続］タブには、
ホストが見つからなくても使えるものが 2 つ出ています。

- **QR コード。**アプリで「QRコードを読み取る」を押します。
- **接続用の文字列**(`prismdesk://…`。横に「コピー」のボタンがあります)。
  アプリで「ほかの繋ぎ方（アドレス指定・USB）」→「ホストを直接指定」を開いて貼り付けます。

**アドレスだけを手で打つより、この 2 つのどちらかを使ってください。**どちらにも PC の
証明書の指紋(`fp=`)が入っているので、端末はネットワークで応答した相手があなたの PC かどうかを
見分けられます。このときアプリには「確認済み」と出ます。アドレスだけを打った場合は指紋を
持っていないので、そのアドレスで最初に応答した相手を信じることになり、印は「暗号化」に留まります。

PC にネットワークアダプタが複数あると(VPN のアダプタも 1 つに数えます)、［接続］タブの
「このホストのアドレス」に一覧が出て、どれを案内するか選べます。選ぶと QR コードも変わります。
端末と同じネットワークのアドレスを選んでください。

## インストーラが開けたポート

PrismDesk は 6 つのポートで待ち受け、インストーラはそれぞれに受信の規則を 1 つずつ足します。

| ポート | | |
|---|---|---|
| 45100 | UDP | 探索(アプリが PC を見つける) |
| 45101 | TCP | 制御(TLS 1.3) |
| 45102 | TCP | 入力 ── タッチ・ペン・キーボード(TLS 1.3) |
| 45103 | UDP | 映像と、接続を保つための定期的な合図(AES-256-GCM) |
| 45104 | UDP | 音声(AES-256-GCM) |
| 45105 | UDP | 端末から PC へ: 合図への返事、再送の要求、カメラ(AES-256-GCM) |

ルーターでのポート転送はいりません。どれも家の中のネットワークだけで使います。
ほかのセキュリティソフトが PrismDesk を許可するか聞いてきたら、許可してください。
規則を消してしまったときは、インストーラをもう一度実行すると戻ります。

## 2 台以上をつなぐ

**PrismDesk Pro** では、1 台の PC に 4 台まで同時につなげます。画面の取り込みと
エンコードは 4 台で 1 つを分け合います。確かめたのが 4 台なので、4 台と書いています
([対応端末](devices.md))。無料版でつなげるのは 1 台です。

## ノート PC で使うとき

USB テザリングを入れると、ノート PC 自身の Wi-Fi の接続が切れることがあります。
両方を使うなら、どちらかを選ぶことになります。[USB でつなぐ](setup-usb.md) を見てください。
