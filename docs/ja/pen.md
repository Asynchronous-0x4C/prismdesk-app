# ペン

端末のスタイラスの筆圧・傾き・回転は、PC に**本物の Windows のペン入力**として届きます。
液晶ペンタブレットが出すのと同じ種類の入力なので、筆圧に対応したアプリにはマウスではなく
ペンとして見えます。

## 届くもの

| | |
|---|---|
| **筆圧** | 確かめました。 |
| **傾き** | 確かめました。 |
| **回転**(ペン軸のひねり) | 確かめました。 |

PrismDesk が入れるのは **Windows の Pointer Input** で、Windows Ink の土台になっている
仕組みです。**WinTab ではありません。**このページで覚えておく価値があるのはこの違いだけです。
アプリにペンが見えるかどうかは、これで決まります。

## アプリがペンに反応しないとき: Windows Ink に切り替える

お絵描きアプリには、古くからある **WinTab** を既定にしているものがあります。WinTab だけを
見ているアプリには、ペンがまったく見えません。筆圧が効かないペン、ではなく、ペンが無いのです。
どの値も一度に全部おかしくなるのが見分けどころです。

**Krita**(確かめました。メニュー名は英語表示のときのものです):

> Settings → Configure Krita… → **Tablet Settings** → *Tablet Input API* →
> **Windows Ink** を選び、Krita を起動し直す。

WinTab を選んでいると、筆圧も傾きも回転も効きませんでした。Windows Ink を選ぶと 3 つとも
効きました。PrismDesk の側は何も変えていません。

Photoshop、Corel Painter、CLIP STUDIO PAINT にも同じような切り替えがあります(たいてい
「Windows Ink を使う」や「WinTab / Windows Ink」のような名前です)。**これらは試していません。**
試したら [端末の報告](https://github.com/Asynchronous-0x4C/prismdesk-app/issues/new?template=device-report.yml) か
[Discussions](https://github.com/Asynchronous-0x4C/prismdesk-app/discussions) で教えてもらえると、このページに載せます。

ブラウザは Pointer Input をそのまま使うので、設定はいりません。筆圧・傾き・回転とも、
何もしなくても効きました。

端末では、最初にペンが触れたときに「ペン入力を受信しました。ペイントソフトが反応しない場合は、
アプリの設定でタブレット入力を Windows Ink にしてください。」と出ます。

## 測っていないこと 2 つ

どちらも、手元の機材のせいではなく、こちらの宿題です。

- **浅い角度での傾きが、思ったより弱く感じられます。**傾きの計算は線形の近似を使っていて、
  その印象とは合います。ただ、描いていての印象で、測ったものではありません。
- **ペンを倒す向きを変えても、ブラシは回りません。**これが正しい動きです(回転はペン軸の
  ひねりに従うもので、倒す向きではありません)。実機でも期待どおりでしたが、コードを見ると
  きちんと確かめるべき箇所があり、まだ確かめていません。

**PrismDesk はどこにも遅延の数字を出していません。**ペンも同じです。出す価値のある測り方を
していないからです。
