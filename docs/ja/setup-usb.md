# USB でつなぐ

PrismDesk に「USB モード」はありません。やることは、Android 端末の
**USB テザリング**をオンにすることだけです。ケーブルが PC と端末をつなぐネットワークになり、
あとは Wi-Fi のときとまったく同じに動きます。

Wi-Fi が混んでいるとき、Wi-Fi を使いたくないとき、どうせ充電もしたいときに使ってください。

## USB テザリングをオンにする

先に端末を PC にケーブルでつなぎます。たいていの Android 端末は、ケーブルがつながっていないと
このスイッチを入れられません。

いちばん確かなのは、アプリから開く方法です。アプリの接続画面で
「ほかの繋ぎ方（アドレス指定・USB）」を開くと、
**「USBテザリング: 有効（USB接続のホストも検索します）」**か
**「USBテザリング: 無効。有線で繋ぐ場合は端末の設定で有効にしてください。」**と出ていて、
横の「設定を開く」でテザリングの画面へ直接移れます(Pixel では
テザリングの画面の 1 つ手前に着きます)。

アプリを使わずに探すなら、端末の設定の検索に「テザリング」と入れてください。
多くの端末では、テザリングやアクセス ポイントの項目の中にあります。

オンにしたら、アプリで「再検索」を押します。Wi-Fi のときと同じように PC が一覧に出ます。

## 何が変わるか

| | |
|---|---|
| **Wi-Fi は切ってもかまいません。** | ケーブルで接続が続きます。 |
| **テザリング中は Wi-Fi 経由ではつながりません。** | PC へはケーブルを通って行きます。 |
| **充電はできます。** | USB で使いながら充電もできます。 |
| **ノート PC では**、USB テザリングを入れると PC 自身の Wi-Fi が切れることがあります。 | Windows が新しくできた接続のほうを優先することがあります。ほかのことに Wi-Fi が要るなら、どちらかを選ぶことになります。 |

## つながらないとき

1. **USB テザリングが本当にオンか確かめてください。**ケーブルを抜くと自動でオフになり、
   挿し直してもオフのままです。
2. **アプリで「再検索」を押してください。**
3. **それでも止まったままなら、まず VPN を疑ってください。**開発中、PC の VPN を
   切るまで何もつながらないことがありました。ケーブルでも Wi-Fi と同じです。
4. それでもだめなら、原因はケーブルより PC 側にあることが多いです。ホストの［接続］タブの
   「準備状況」を見て、[困ったときは](troubleshooting.md) でほかに PC が見えなくなる原因を
   確かめてください。それでもつながらなければ、診断ファイルを付けて
   [issue](https://github.com/Asynchronous-0x4C/prismdesk-app/issues/new/choose) を開いてください。
