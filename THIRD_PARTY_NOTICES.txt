8. NVIDIA Video Codec SDK interface headers
-----------------------------------------------------------------------------

   Source     : NVIDIA Video Codec SDK (interface headers only)
   Version    : NVENCAPI 13.1
   Copyright  : Copyright (c) 2010-2026 NVIDIA Corporation
   License    : MIT License (applies to the header file only)
   Used in    : WindowsHost.exe

   Three headers are used: nvEncodeAPI.h (NVENC), and nvcuvid.h and
   cuviddec.h (NVDEC). PrismDesk calls the NVIDIA encoder and decoder at
   runtime through them. No NVIDIA library or sample code is distributed with
   PrismDesk; nvEncodeAPI64.dll and nvcuvid.dll are part of the NVIDIA display
   driver already installed on the user's computer.

   These headers come from the NVIDIA Video Codec SDK itself, not from the
   FFmpeg/nv-codec-headers mirror: that project carries a different version of
   nvEncodeAPI.h and does not carry nvcuvid.h or cuviddec.h at all.
